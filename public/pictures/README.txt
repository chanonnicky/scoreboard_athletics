โลโก้โรงเรียน / รูปประกอบ CG
============================

logo.png ในโฟลเดอร์นี้ = โลโก้โรงเรียน (ย่อจาก Picture/SD_logo.png เหลือ 600x600)
CG ทุกอัน (แถบล่าง + เต็มจอ) ดึงรูปจากพาธ /pictures/logo.png โดยอัตโนมัติ

เปลี่ยนโลโก้:
  - แทนที่ไฟล์ logo.png ในโฟลเดอร์นี้ (PNG พื้นหลังโปร่งใส สูง ~400-600px กำลังดี), หรือ
  - เปลี่ยนพาธที่หน้า Control -> แท็บ "ตั้งค่า" -> ช่อง "โลโก้โรงเรียน"

ปิดโลโก้: เว้นช่อง "โลโก้โรงเรียน" ในแท็บตั้งค่าให้ว่าง

รองรับ .png .jpg .jpeg .webp .svg
ถ้าลบไฟล์ทิ้ง CG จะแสดงตามปกติ ไม่มีรูปแตก
