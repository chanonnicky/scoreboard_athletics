# CG Live — ระบบกราฟิกสด (CG) สำหรับงานถ่ายทอดสด

ระบบ Character Generator (CG) แบบเว็บ ออกจอ **OBS และ vMix พร้อมกัน** ที่ 1920×1080
พื้นหลังโปร่งใส — คุมจากหน้าเว็บ ทุกเครื่อง/ทุกแท็บซิงก์ข้อมูลกันเอง

**มี 2 ผลิตภัณฑ์ในระบบเดียว** เลือกที่หน้าแรก (`/`) หรือแท็บ "ตั้งค่า":

| | ทำอะไร | ใช้จอ |
|---|---|---|
| **🏟️ งานกีฬา** | งานกีฬาสีโรงเรียน — ผลกรีฑาอันดับ 1–3 (รายคณะสี / รายโรงเรียน), สกอร์กีฬาสด (ฟุตซอล/บาส), กราฟเหรียญ | `/live` + `/scoreboard` |
| **🎬 งานทั่วไป** | ตัวสร้าง **Lower Third สด** สำหรับงานทั่ว ๆ ไป (พิธีเปิด, สัมมนา, แถลงข่าว) — พิมพ์ชื่อ/หัวข้อแล้วสั่งขึ้นจอสด + rundown พรีเซ็ต | `/live` เท่านั้น |

> สลับผลิตภัณฑ์ = สลับ **ชุดข้อมูล / โลโก้ / ธีม / ชื่องาน** ทั้งหมด · อีกชุดถูกเก็บไว้ครบ
> กลับมาเหมือนเดิมเมื่อสลับกลับ (เหมือนการสลับโหมดคณะสี ↔ โรงเรียน)

**และมีช่องสัญญาณที่ 2 ที่ใช้พร้อมกันได้** (ไม่ต้องสลับ ไม่เกี่ยวกับผลิตภัณฑ์ข้างบน):

| | ทำอะไร | ใช้จอ |
|---|---|---|
| **🎬 Lower Third / Bar** | ตัวสร้าง Lower Third และแถบต่าง ๆ แบบ **custom 17 ชนิด** — ชื่อ-ตำแหน่ง, แถบวิ่ง, ถัดไป, ลำดับรายการ, นับถอยหลัง, สปอนเซอร์ ฯลฯ ปรับสี/ขนาด/ตำแหน่ง/แอนิเมชันเองได้ · คุมที่ `/cg` | `/live/cg` (Browser Source คนละตัว) |

> ช่องนี้แยกข้อมูลของตัวเองที่ `state.l3` — **ออกจอพร้อมงานกีฬาได้ คนละคนคุมคนละเครื่อง**
> และมี **OBS plug-in** (Custom Browser Dock + สคริปต์ hotkey) ให้คุมจากใน OBS เลย

- เซิร์ฟเวอร์เป็น **PowerShell ล้วน** (`server.ps1`) — มีติดมากับ Windows ทุกเครื่อง ไม่ต้องติดตั้งอะไรเลย
  (มี `server.py` เวอร์ชัน Python ให้ด้วย ถ้าเครื่องมี Python — ได้ SSE เรียลไทม์เต็มรูปแบบ)
- Overlay เป็นหน้าเว็บพื้นหลังโปร่งใส ใส่เป็น Browser Source (OBS) / Web Browser (vMix)
- หน้า Control สั่งขึ้น–ลง CG — overlay อัปเดตตามอัตโนมัติ (PowerShell = polling ~0.25 วิ, Python = SSE ทันที)

```
เครื่อง B  ── start.bat ──►      http://<ip-B>:8080/live       (CG งานกีฬา)
                             └─► http://<ip-B>:8080/live/cg    (Lower Third / Bar)
                                        │
              เครื่อง A  ── OBS  ───────┤  (Browser Source, 1920×1080 — ใส่ได้ทั้ง 2 ตัว)
                          └─ vMix ──────┘  (Web Browser input, 1920×1080)
```

## เริ่มใช้งาน (เครื่อง B — เครื่องที่รันระบบ)

1. **ครั้งแรกครั้งเดียว:** ดับเบิลคลิก **`setup.bat`** → กด **Yes** ตอนถามสิทธิ์ Administrator
   (เปิดพอร์ต 8080 + firewall ให้เครื่องอื่นเข้าถึงได้)
   *ถ้าข้ามขั้นนี้ `start.bat` จะเด้ง UAC ขอสิทธิ์ให้เองในการรันครั้งแรก*
2. ดับเบิลคลิก **`start.bat`**
3. หน้าต่างจะพิมพ์ URL ออกมา เช่น
   ```
   Control :  http://192.168.1.131:8080/control
   Score   :  http://192.168.1.131:8080/score     <<  หน้าจดคะแนน (งานกีฬา)
   Live    :  http://192.168.1.131:8080/live      <<  ใส่ใน OBS / vMix
   ```
4. เปิด **หน้าแรก** `http://<ip>:8080/` เลือกผลิตภัณฑ์ที่จะใช้ แล้วเปิด **Control** (คนสั่ง CG)
   — คนละเครื่อง/แท็บก็ได้ ข้อมูลซิงก์กันอัตโนมัติ

ตัวเลือกตอนสั่ง (PowerShell):
```
powershell -ExecutionPolicy Bypass -File server.ps1 -Port 8080 -Token MYSECRET
```
- `-Port` = เปลี่ยนพอร์ต (ถ้าเปลี่ยน ต้องรัน `setup.bat 9000` ด้วยพอร์ตใหม่)
- `-Token` = ถ้าตั้ง ต้องใส่ token เดียวกันในหน้า Control ก่อนจึงสั่งงานได้ (ควรตั้งเมื่อใช้ผ่านอินเทอร์เน็ต)
- `-ListenHost localhost` = ทดสอบบนเครื่องเดียว ไม่ต้องใช้ Administrator

### ใช้ Python แทน (ถ้าเครื่องมี Python 3)
```
python server.py --port 8080 --token MYSECRET
```
เวอร์ชันนี้ push ผ่าน SSE — overlay อัปเดตทันที ไม่ต้อง `setup.bat` (แต่ยังต้องเปิด firewall)
```
netsh advfirewall firewall add rule name="CG Live" dir=in action=allow protocol=TCP localport=8080
```

### macOS / Linux (ใช้ `start.sh`)
```
./start.sh                  # พอร์ต 8080 (ค่าเริ่มต้น)
./start.sh --port 9000      # กำหนดพอร์ตเอง
```
`start.sh` จะหา Python 3 ให้เอง และส่ง argument (`--port`, `--host`, `--token`) ต่อไปให้ `server.py`
ครั้งแรกถ้ารันไม่ได้ ให้เปิดสิทธิ์ก่อนด้วย `chmod +x start.sh`

**ให้เครื่องอื่นใน wifi เดียวกันเข้าถึง (macOS):**
- `start.sh` เลือกใช้ **system python ของ macOS** (`/usr/bin/python3`) โดยอัตโนมัติ
  เพราะ python จาก conda/homebrew เป็น unsigned → macOS firewall จะบล็อกการเชื่อมต่อจากเครื่องอื่น
  (เข้าจาก `127.0.0.1` ได้ แต่จาก LAN IP ไม่ได้)
- ดู LAN IP ของเครื่องที่รัน:  `ipconfig getifaddr en0`
- เครื่องอื่นเปิดเบราว์เซอร์ไปที่ `http://<LAN-IP>:8080/control` (หรือ `/live`, `/score`)
- ถ้าเข้าไม่ได้: ทั้งสองเครื่องต้องอยู่ wifi/subnet เดียวกัน และครั้งแรกที่รัน หาก macOS เด้งถาม
  "อนุญาตการเชื่อมต่อขาเข้า" ให้กด **Allow**

## ตั้งค่าเครื่อง A (เครื่องที่มี OBS + vMix)

ใช้ URL `http://<ip-เครื่อง-B>:8080/live`

### OBS
Sources → ➕ → **Browser**
- URL: `http://<ip-B>:8080/live`
- Width `1920`  Height `1080`
- เอาติ๊ก **"Shutdown source when not visible"** ออก
- ไม่ต้องใส่ Custom CSS (หน้าเพจโปร่งใสอยู่แล้ว)

### vMix
Add Input → **More…** → **Web Browser**
- URL: `http://<ip-B>:8080/live`
- Width `1920`  Height `1080`
- ปิด **Interactive** (กันเมาส์ไปโดน)
- vMix Web Browser รองรับพื้นหลังโปร่งใส (alpha) อยู่แล้ว

> อยากได้เฉพาะบางส่วน: `…/live?slot=lower` (แถบล่าง) · `?slot=full` (เต็มจอ) · `?slot=bug` (Score bug)
> · `/overlay` เป็นชื่อเดิมของ `/live` (ใช้ได้เหมือนกัน)

### Browser Source ตัวที่ 2 — ช่อง Lower Third / Bar
ถ้าจะใช้ Lower Third / แถบวิ่ง / สปอนเซอร์ ให้เพิ่ม Browser Source **อีกตัว** ตั้งค่าเหมือนกัน
แต่ URL เป็น `http://<ip-B>:8080/live/cg` — เป็นช่องสัญญาณคนละชุด คุมจากหน้า `/cg`
ออกจอพร้อมกับ CG งานกีฬาได้เลย (ดูหัวข้อ "🎬 ช่อง Lower Third / Bar" ด้านล่าง)
ถ้าติดตั้งสคริปต์ `cglive.lua` ใน OBS กดปุ่มเดียวให้มันสร้าง Source ทั้งสองตัวได้

## กรณีเครือข่าย (A กับ B เชื่อมกันยังไง)

### 1) อยู่ LAN วงเดียวกัน
ใช้ IP เครื่อง B ตรง ๆ เช่น `http://192.168.1.131:8080/live` + เปิด firewall ตามด้านบน

### 2) คนละ subnet แต่ route ถึงกัน (LAN โรงเรียนวงใหญ่)
- ใช้ IP เครื่อง B ที่เครื่อง A มองเห็น (ถามผู้ดูแลเครือข่ายถ้าไม่แน่ใจ)
- ทดสอบก่อนงาน: บนเครื่อง A เปิด CMD แล้วพิมพ์ `curl http://<ip-B>:8080/healthz` ต้องได้คำว่า `ok`
- ถ้ามี VLAN/ไฟร์วอลล์กั้น ให้ผู้ดูแลเปิด TCP 8080 จาก subnet ของ A ไป B

### 3) คนละเน็ต / ผ่าน NAT / ผ่านอินเทอร์เน็ต / เน็ตมือถือ  →  ใช้ Tailscale
1. ติดตั้ง [Tailscale](https://tailscale.com/download) ทั้งสองเครื่อง ล็อกอินบัญชีเดียวกัน
2. แต่ละเครื่องจะได้ IP ถาวรขึ้นต้น `100.x.x.x`
3. ใน OBS/vMix ใช้ `http://100.x.x.x:8080/live` (x = ของเครื่อง B) — ไม่ต้องแตะ firewall/พอร์ตฟอร์เวิร์ด
4. ตั้ง token ด้วยเสมอเมื่อวิ่งข้ามอินเทอร์เน็ต (`-Token MYSECRET` / `--token MYSECRET`)

ทางเลือกอื่น: `cloudflared tunnel` เปิดพอร์ต 8080 เป็น URL HTTPS สาธารณะ (เหมาะเมื่อ operator อยู่คนละที่กับทั้ง A และ B)

### ถ้า overlay ไม่อัปเดต (บางเครือข่าย/พร็อกซีบล็อก SSE)
ใช้ `http://<ip-B>:8080/live?transport=poll` แทน — จะดึงข้อมูลใหม่ทุก ~0.5 วินาที

## RTMP relay — OBS หน้างาน → เข้า OBS อีกตัว

ใช้เมื่อ **OBS อยู่หน้างาน** แต่ **เครื่องที่รันระบบอยู่รีโมต** (มี public IP) และ **OBS ตัวที่ตัดต่อ
จริง (OBS #2) อยู่อีกที่** — เครื่องรีโมตเป็นจุดพักสัญญาณ (RTMP relay)

```
OBS หน้างาน ──RTMP publish──► เครื่องรีโมต (MediaMTX) ──RTMP pull──► OBS #2
                                    │                                  │ Media Source
                              + อัด .mp4 สำรอง (option)         ซ้อน CG /live (โปร่งใส) แล้วออกอากาศ
```

- **ไม่ re-encode** — MediaMTX รีเลย์สตรีมดิบ → latency เพิ่มแค่ ~0.1–0.5 วิ + 1 hop เน็ต, CPU แทบไม่ขยับ
- CG server (`server.ps1`/`server.py`) **ไม่เกี่ยวกับวิดีโอเลย** — relay เป็นคนละโปรแกรม
  (`mediamtx.exe`) รันคู่กันในหน้าต่างแยก
- OBS #2 ยังดึง `http://<รีโมต>:8080/live` ไปซ้อน CG เองเหมือนเดิม

### ติดตั้ง (เครื่องรีโมต, Windows)

1. `powershell -ExecutionPolicy Bypass -File get-relay.ps1`
   โหลด `mediamtx.exe` + `ffmpeg.exe` (ไฟล์พกพา ไม่ติดตั้ง) ลง `bin\` — ต้องมีเน็ตครั้งเดียว ·
   สร้าง `mediamtx.yml` จาก `mediamtx.example.yml` ให้ด้วย (`mediamtx.yml` ไม่เข้า git)
   *ไม่มีเน็ต:* โหลด [MediaMTX](https://github.com/bluenviron/mediamtx/releases) (windows_amd64)
   กับ [ffmpeg](https://github.com/BtbN/FFmpeg-Builds/releases) (win64-gpl) เอง แล้ววางเป็น
   `bin\mediamtx\mediamtx.exe` และ `bin\ffmpeg\ffmpeg.exe`
2. แก้ **`mediamtx.yml`** — ตั้งรหัส 2 อันใน `authInternalUsers`:
   - `user: publish` → `pass:` = รหัสที่ OBS หน้างานต้องใส่
   - `user: read` → `pass:` = รหัสที่ OBS #2 ต้องใส่ตอนดึง
   - (option) อัดไฟล์สำรอง: `record: false` → `true` (`data\rec\` ~3.6 GB/ชม. ที่ 8 Mbps)
   - (option) ยิงต่อไปที่อื่นด้วย (YouTube/ห้องถ่ายทอด): เปิดคอมเมนต์ 2 บรรทัด `runOnAvailable`
3. `setup.bat` — เปิด firewall **1935** ให้แล้ว (รันครั้งเดียว) + ทำ **port-forward มาที่ 1935/tcp
   ของเครื่องนี้** ที่เราเตอร์/cloud (พอร์ตภายนอกจะเป็นเลขอะไรก็ได้ เช่น 7445)
4. `start.bat` — เจอ `bin\mediamtx\mediamtx.exe` จะเปิด relay ในหน้าต่าง "CG Relay" ให้เอง

### ตั้งค่า OBS ทั้งสองตัว — ดูจากในเว็บ

**`/control` → แท็บ "ตั้งค่า" → การ์ด "RTMP relay"** โชว์ URL พร้อมปุ่มคัดลอก + สถานะสด:

- **พอร์ตภายนอก** — ใส่เลขที่ port-forward มาจากภายนอก (เช่น 7445) · เก็บในเว็บ ไม่ต้องแก้ไฟล์
- **1) OBS หน้างาน — ส่งเข้า:** Settings → Stream → Custom · Server + Stream Key จากการ์ด
  · ฝั่ง Output: CBR, **Keyframe 1s**, preset latency ต่ำ
- **2) OBS #2 — ดึงออก:** Sources → ➕ → **Media Source** → เอาติ๊ก "Local File" ออก →
  วาง URL จากการ์ดในช่อง Input → เปิด "Reconnect"

### latency / โหลด / แบนด์วิดท์

| จุด | หมายเหตุ |
|---|---|
| OBS หน้างาน | keyframe 1s, CBR, preset low-latency, buffer เล็ก |
| relay | รีเลย์ดิบ ไม่ transcode — CPU ~2–5% ของ 1 core, RAM หลักสิบ MB |
| OBS #2 (Media Source) | buffer ~2–4 วิ · ถ้าต้องต่ำกว่านี้มากใช้ SRT แทน (แก้ `srt: true` + streamid) |
| แบนด์วิดท์เครื่องรีโมต | ≈ บิตเรตเข้า + (บิตเรต × จำนวน OBS ที่ดึง) · 1080p 10 Mbps + ดึง 1 ตัว ≈ 20 Mbps ทั้ง up/down |
| ดิสก์ (ถ้าอัด) | ~3.6 GB/ชม. ที่ 8 Mbps |

> hop สนาม→รีโมต เป็น latency ที่เลี่ยงไม่ได้เพราะเครื่องอยู่รีโมต — relay เองเพิ่มน้อยมาก
> · OBS หลุดแล้วต่อใหม่: MediaMTX รับต่อเอง, OBS #2 (เปิด Reconnect) ดึงต่อเอง

## หน้าเว็บทั้งหมด

| URL | ใช้ทำอะไร | ผลิตภัณฑ์ |
|---|---|---|

| `/control` | หน้าคุม operator — สั่งขึ้น/ลง CG + พรีวิวสด | ทั้งคู่ (หน้าตาต่างกันตามผลิตภัณฑ์) |

| `/scoreboard` (= `/board`) | จอประชาสัมพันธ์ วนผลทั้งหมด (`?view=all\|results\|chart\|<กีฬา>`) | งานกีฬา |

| `/live/cg` | จอโปร่งใสของช่อง Lower Third — Browser Source ตัวที่ 2 | ทั้งคู่ |
| `/obs` | หน้าคุมแบบแคบ สำหรับใส่เป็น Custom Browser Dock ใน OBS | ทั้งคู่ |

> ในโหมด **งานทั่วไป** `/score*` และ `/scoreboard*` ไม่มีการใช้งาน (เปิดได้แต่จะขึ้นข้อความว่าง/แจ้งเตือน)

# 🏟️ งานกีฬา

> ระบบนี้แสดง **"ผู้เข้าแข่งขัน" อย่างเดียว ไม่มีชื่อนักกีฬา** (คิดผลเป็นรายคณะ / รายโรงเรียน)

### 2 โหมด (สลับที่แท็บ "ตั้งค่า")

- **กีฬาสีภายใน** — 4 คณะสีตายตัว (แดง = Red Falcon, ฟ้า = Blue Shark, เขียว = Green Dragon,
  เหลือง = Gold Lion) แก้ชื่อ/สี/โลโก้ได้ในแท็บตั้งค่า
- **แข่งกับโรงเรียนภายนอก** — เพิ่มรายชื่อโรงเรียนเองได้ไม่จำกัด แต่ละโรงเรียนใส่ **ชื่อ + โลโก้
  (กด "เลือกไฟล์" อัปโหลดรูป PNG/JPG/WebP พื้นหลังโปร่งใส — รูปใหญ่ระบบย่อ/บีบให้อัตโนมัติ)**
  แล้วกด **"บันทึกการตั้งค่า"**

**สลับโหมดจะสลับชุดข้อมูลทั้งชุด** (รายการแข่ง / ผล / แมตช์กีฬา) — ข้อมูลของอีกโหมดถูกเก็บไว้
ครบ กลับมาเหมือนเดิมเมื่อสลับกลับ · หน้าจดคะแนน/สั่ง CG ใช้งานเหมือนกันทั้งสองโหมด
(แตะ "โรงเรียน" เรียงอันดับแทน "สีคณะ")

### หน้าจดคะแนน

- **`/score`** — คนจดคะแนนกรีฑา: เลือกรายการ (ปุ่ม ‹ ก่อนหน้า / ถัดไป ›), **แตะสีคณะเรียงตามลำดับ
  เข้าเส้น** เพื่อกรอกอันดับ — บันทึก + อัปเดต CG อัตโนมัติ ไม่ต้องกดบันทึก
- **`/score/<กีฬา>`** — จดคะแนนฟุตซอล/บาส: แก้ตารางแมตช์, กด "ตั้งสด" ให้คู่ที่กำลังแข่ง,
  ปุ่ม +/- และพิมพ์สกอร์ตรง, นาฬิกานับถอยหลัง (เริ่ม/หยุด · ±1:00 / ±0:10 · รีเซ็ต)

### ช่องแสดงผล (slot) บนจอ Live

- **กราฟิกหลัก — `แถบล่าง` กับ `เต็มจอ` ขึ้นได้ทีละอันเดียว** (ขึ้นอันใหม่ อันเดิมลงเอง)
  - `แถบล่าง` — **อันดับ 1–3** (แถบยาว เหรียญ 1/2/3) หรือ **สด <กีฬา>** (แถบสกอร์คู่เต็มความกว้าง)
  - `เต็มจอ` — 4 แบบ:
    - **ตารางการแข่งขัน** — หน้าต่าง ~11 รายการรอบ ๆ รายการที่เลือก เลื่อนตามอัตโนมัติ
    - **ผลการแข่งขัน** — ทุกรายการ + สีคณะที่ได้อันดับ 1/2/3 (รายการที่ยังไม่แข่ง = "รอผล"); แบ่งหน้า สลับเองทุก 10 วิ

ปุ่ม "ซ่อนแถบล่าง"/"ซ่อนเต็มจอ" = ลงกราฟิกหลักทั้งคู่ (Score bug ค้างต่อ) · "ลงจอทั้งหมด" = ลงหมดทุกช่อง

# 🎬 งานทั่วไป (Lower Third)

สำหรับงานที่ไม่ใช่กีฬา — พิธีเปิด, สัมมนา, แถลงข่าว, งานเลี้ยง ฯลฯ **ไม่มีการจดคะแนน**
operator พิมพ์ข้อความแล้วสั่งขึ้น/ลงจอ `/live` สด (ใช้จอ Live อย่างเดียว)

### CG 3 แบบ
| แบบ | ช่อง | ใส่อะไร |
|---|---|---|
| **ชื่อ + ตำแหน่ง** | แถบล่าง | 2 บรรทัด — ชื่อ + ตำแหน่ง/คำบรรยาย |
| **หัวข้อ** | แถบล่าง | บรรทัดเดียว — หัวข้อ/ประเด็น |
| **การ์ดเต็มจอ** | เต็มจอ | หัวเรื่อง + คำบรรยายรอง (ไม่บังคับ) |

"แถบล่าง" กับ "เต็มจอ" ขึ้นได้ทีละอันเดียว (ขึ้นอันใหม่ อันเดิมลงเอง)

### หน้า `/control` (งานทั่วไป)

1. **กำลังออกอากาศ** — แถบบนสุด โชว์ข้อความจริงที่ขึ้นจอตอนนี้ + ปุ่ม ✕ ลงจอ ต่อช่อง
   · ปุ่ม "■ ลงจอทั้งหมด"
2. **คอมโพส** — กล่องเดียว
   - แถบเลือกชนิด: `[ชื่อ + ตำแหน่ง] [หัวข้อ] [การ์ดเต็มจอ]`
   - พิมพ์ข้อความ → **▶ ขึ้นจอ** (หรือกด **Enter** ในช่องข้อความ)
   - **★ บันทึกเป็นพรีเซ็ต** — เก็บข้อความชุดนี้ไว้ในรายการ rundown
3. **พรีเซ็ต (rundown)** — บันทึกข้อความไว้ล่วงหน้า
   - **คลิกที่แถว = ขึ้นจอทันที**
   - แถวที่กำลังออกจะไฮไลต์เขียว (● ออกอยู่) · ปุ่ม **"■ ลงจอ"** ที่หัวการ์ด = เอาพรีเซ็ตที่ออกอยู่ลง
   - ปุ่ม "แก้" = โหลดข้อความเข้ากล่องคอมโพส (แล้ว ★ อัปเดตพรีเซ็ต จะทับอันเดิม) · "✕" = ลบ
4. **พรีวิว** — คอลัมน์ขวา อัปเดตสดเหมือนที่ออกใน OBS/vMix

### แท็บ "ตั้งค่า" (งานทั่วไป)
ผลิตภัณฑ์, ธีมแสดงผล, ชื่องาน, โลโก้ส่วนกลาง, ความเร็ว animation, ลิงก์จอ Live, รีเซ็ตข้อมูล

# 🎬 ช่อง Lower Third / Bar (`/cg`) — ช่องสัญญาณที่ 2

> **นี่คือทางหลักที่แนะนำสำหรับทำ Lower Third** · ผลิตภัณฑ์ "งานทั่วไป" เดิมยังอยู่

> ส่วนช่องนี้มี **17 ชนิด ปรับแต่งได้** และ **ใช้พร้อมงานกีฬาได้เลย**

## ต่างจากของเดิมอย่างไร

ช่องนี้เป็น **ช่องสัญญาณคนละชุด** ไม่ใช่ "ผลิตภัณฑ์" — ข้อมูลอยู่ที่ `state.l3` แยกจากทุกอย่าง
จึง **ไม่ถูกแตะเลย** เมื่อสลับผลิตภัณฑ์ (`setApp`) สลับโหมด (`setMode`) หรือรีเซ็ต (`resetState`)

```
OBS
 ├─ Browser Source  http://<ip>:8080/live       ← CG งานกีฬา (คุมที่ /control)
 └─ Browser Source  http://<ip>:8080/live/cg    ← Lower Third / Bar (คุมที่ /cg)
```

ออกจอ **พร้อมกัน** ได้ · **คนละคนคุมคนละเครื่อง** ได้ · ช่องนี้จำ **ธีม / โลโก้ / สีเน้น**
ของตัวเอง ไม่ปนกับงานกีฬา

| ช่อง | ตำแหน่ง | กันกับใคร |
|---|---|---|
| `เต็มจอ` | กลางจอ | กันกับ "แถบล่าง" (ขึ้นได้ทีละอัน) |
| `แถบล่าง` | ล่าง (เหนือแถบวิ่ง) | กันกับ "เต็มจอ" |
| `แถบบน` | บนจอ (ประกาศด่วน) | อิสระ — ค้างจอพร้อมอันอื่นได้ |
| `แถบวิ่ง` | ล่างสุด เต็มความกว้าง | อิสระ |
| `มุมจอ` | มุมซ้ายบน (นาฬิกา/โลโก้) | อิสระ |

แยกเป็น Browser Source ต่อช่องก็ได้: `/live/cg?slot=ticker` · `?slot=lower` · `?slot=top` · `?slot=bug`

## 17 ชนิด CG

| ชุด | ชนิด |

| **สปอนเซอร์ / โลโก้** | แถบสปอนเซอร์ (วนโลโก้) · สนับสนุนโดย · โลโก้มุมจอ |

**ปรับแต่งได้ต่อชิ้น:** สีเน้น · สีตัวอักษร · พื้นหลัง (ทึบ/ไล่สี/กระจก/ไม่มี) · การจัดวาง
(ซ้าย/กลาง/ขวา) · ขนาด (เล็ก/กลาง/ใหญ่) · แอนิเมชัน (เลื่อน/จาง/ปาด/พิมพ์) · ฟอนต์ ·
โลโก้ · **ลงจออัตโนมัติกี่วินาที**
ค่าที่ไม่ตั้ง = ใช้ "ค่าตั้งต้นของช่อง" ในแท็บตั้งค่า

## 🧩 OBS plug-in

มี 2 ส่วน ใช้ร่วมกันหรือแยกกันก็ได้ — **ไม่ต้องติดตั้ง plugin `.dll`**

### 1) หน้าคุมใน OBS (Custom Browser Dock) — แนะนำ

OBS → **Docks → Custom Browser Docks…** → ตั้งชื่อ `CG Live` → URL `http://<ip>:8080/obs` → **Apply**

จะได้แผงคุมอยู่ในหน้าต่าง OBS เลย: สถานะ 5 ช่อง · ปุ่มลงจอ · ปุ่มชิ้นงานทั้งคลัง ·
ช่องพิมพ์ชื่อ-ตำแหน่งด่วน (งานละเอียดทำที่ `/cg`)

### 2) สคริปต์ hotkey + สร้าง Browser Source ให้อัตโนมัติ

1. ดาวน์โหลด `http://<ip>:8080/obs/cglive.lua` (มีลิงก์ให้ในแท็บ "ตั้งค่าช่อง" ของ `/cg`)
2. OBS → **Tools → Scripts → ➕** → เลือกไฟล์นั้น
3. ใส่ **Server URL** (`http://<ip>:8080`) และ **Token** ถ้าตั้งไว้ → กด **Test connection**
4. กด **Create CG Live scene + sources** → ได้ scene `CG Live` พร้อม Browser Source 2 ตัว
   ที่ 1920×1080 และปิด *Shutdown source when not visible* ให้เรียบร้อย
5. ผูกปุ่มลัดที่ **Settings → Hotkeys** — หาคำว่า `CG Live:`
   - `hide all` / `hide main graphic`
   - `air item 1` … `air item 20` = ชิ้นงานลำดับที่ 1–20 ในคลัง (ตามลำดับที่เห็นใน `/cg`)

> สคริปต์ใช้ `curl` ส่งคำสั่ง (Windows 10/11 และ macOS มีมาให้แล้ว) · ไม่มีหน้าต่าง console
> เด้ง · ถ้าเครื่องไม่มี `curl` ดูหมายเหตุท้ายไฟล์ `cglive.lua`
>
> **ทำไมไม่ทำ plugin `.dll` จริง:** ต้องมี C++ toolchain และต้อง build ใหม่ทุกครั้งที่ OBS
> อัปเกรด แต่ไม่ได้ความสามารถเพิ่มจาก dock + สคริปต์ — จึงเลือกทางนี้

> หมายเหตุออฟไลน์: ฟอนต์ LINE Seed โหลดจาก jsDelivr ถ้าหน้างานไม่มีอินเทอร์เน็ต
> จะตกไปใช้ฟอนต์สำรองของเครื่อง (ดูบล็อก `@font-face` ที่คอมเมนต์ไว้ใน `public/overlay.css`)

## โครงสร้างไฟล์
```
server.ps1                        เซิร์ฟเวอร์ PowerShell (ค่าเริ่มต้น)
server.py                         เซิร์ฟเวอร์ Python (ทางเลือก, ได้ SSE)
start.bat                         ตัวเปิด (เรียก server.ps1 + relay ถ้ามี)
start.sh                          ตัวเปิดบน macOS / Linux (เรียก server.py)
setup.bat                         ตั้งค่าพอร์ต + firewall ครั้งเดียว (ขอสิทธิ์ admin)
get-relay.ps1                     โหลด mediamtx.exe + ffmpeg.exe ลง bin\ (ทางเลือก, RTMP relay)
mediamtx.example.yml              เทมเพลตคอนฟิก RTMP relay (ก๊อปเป็น mediamtx.yml อัตโนมัติ)
mediamtx.yml                      คอนฟิก relay ที่ใช้จริง (แก้รหัส 2 อัน · ไม่เข้า git)
bin/                              ไบนารี relay (สร้างจาก get-relay.ps1, ไม่เข้า git)
data/rec/                         ไฟล์อัดสำรองจาก relay (สร้างอัตโนมัติ, ไม่เข้า git)
public/                           หน้าเว็บ (control / overlay / board / home)
public/cg.html  cg.js  cg.css     หน้าคุมช่อง Lower Third / Bar (/cg)
public/l3.css                     สไตล์ CG ของช่อง Lower Third (โหลดใน overlay.html)
public/obs.html  obs.js           หน้าคุมแบบแคบสำหรับ Custom Browser Dock ของ OBS (/obs)
public/obs/cglive.lua             สคริปต์ OBS — hotkey + สร้าง Browser Source ให้
tools/check-*.js                  ชุดตรวจงานด้วย node (ไม่ต้องเปิดเบราว์เซอร์ · ดู tools/README.txt)
data/state.default.json           ข้อมูลตั้งต้น งานกีฬา โหมดคณะสี (มีรายการตัวอย่าง)
data/state.default.school.json    ข้อมูลตั้งต้น งานกีฬา โหมดแข่งภายนอก (ว่าง)
data/state.default.general.json   ข้อมูลตั้งต้น งานทั่วไป (ว่าง)
data/state.default.l3.json        ข้อมูลตั้งต้น ช่อง Lower Third (มีชิ้นงานตัวอย่าง 3 ชิ้น)
data/state.json                   ข้อมูลใช้งานจริง (สร้างอัตโนมัติ, ไม่เข้า git)
data/uploads/                     รูปโลโก้ที่อัปโหลด (สร้างอัตโนมัติ, ไม่เข้า git)
```

ข้อมูลถูกบันทึกลง `data/state.json` อัตโนมัติ ปิด–เปิดเซิร์ฟเวอร์ใหม่ข้อมูลไม่หาย
(ทั้งผลิตภัณฑ์ที่ใช้อยู่ และผลิตภัณฑ์/โหมดที่พักไว้) · รีเซ็ตกลับค่าตั้งต้นได้จากแท็บ "ตั้งค่า"
(รีเซ็ตเฉพาะผลิตภัณฑ์ที่ใช้อยู่ อีกผลิตภัณฑ์ไม่ถูกแตะ)

ช่อง **Lower Third / Bar** เก็บแยกที่คีย์ `l3` ในไฟล์เดียวกัน — ไม่ถูกแตะเมื่อสลับผลิตภัณฑ์
สลับโหมด หรือรีเซ็ต · รีเซ็ตช่องนี้แยกได้จากแท็บ "ตั้งค่าช่อง" ใน `/cg`
(ถ้าลบคีย์ `l3` ออกจาก `state.json` เซิร์ฟเวอร์จะสร้างใหม่จาก seed ให้เองตอนเปิด)
